# Naava Naslavsky — whimsical paper mâché sculptures

Source for the new website (replacing the old naavanaslavsky.com site).

- `mockups/` — three design directions under review (A: Paper & Ink, B: Gallery, C: Playful Studio)
- `assets/img/` — web-sized photos of the sculptures
- `data/works.json` — the catalog (titles, categories); `data/arrangement.json` — chosen front page, featured works and gallery order
- `tools/` — build scripts (`build_images.py`, `build_mockups.py`) and a small local server for the arrangement tool (`arrange/`)
