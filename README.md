# Naava Naslavsky — whimsical paper mâché sculptures

Source of the website for Naava Naslavsky's paper mâché sculptures (replacing the old naavanaslavsky.com site). Served with GitHub Pages from the root of `main`.

- `index.html`, `gallery.html`, `cat-*.html`, … — the site pages (generated; don't edit by hand)
- `css/`, `js/` — styles and behaviour (gallery viewer, contact form)
- `assets/img/` — web-sized photos of the sculptures, including extra viewing angles
- `data/works.json` — the catalog (titles, categories); `data/arrangement.json` — front page, featured works and gallery order
- `tools/build_images.py`, `tools/build_site.py` — rebuild the images and pages

The contact form is forwarded to Naava's email by FormSubmit (free).
